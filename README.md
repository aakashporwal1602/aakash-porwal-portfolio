# 🚀 Aakash Porwal — Portfolio

A stunning, dark-themed personal portfolio website built with **pure HTML, CSS & JavaScript** — no frameworks, no dependencies. Designed to showcase my engineering impact at scale.

🌐 **Live Site:** [https://aakashporwal1602.github.io/aakash-porwal-portfolio](https://aakashporwal1602.github.io/aakash-porwal-portfolio)

---

## ✨ Features

- 🌑 **Dark glassmorphism design** with gradient accents
- ✍️ **Typing animation** cycling through specialties
- 🔢 **Animated number counters** for impact metrics
- 🎆 **Particle background** with connected dots (Canvas API)
- 📜 **Scroll-triggered reveal animations** (Intersection Observer)
- 📱 **Fully responsive** — mobile, tablet, desktop
- 🧭 **Sticky navbar** with active section highlighting
- ⬆️ **Scroll-to-top button**
- ⚡ **Zero dependencies** — fast, lightweight, free to host

## 📁 Project Structure

```
aakash-porwal-portfolio/
├── index.html    # Main HTML — all sections & content
├── style.css     # Styles — dark theme, glassmorphism, animations, responsive
├── script.js     # JavaScript — typing effect, particles, counters, scroll logic
└── README.md     # You're reading this!
```

### `index.html`
The single-page portfolio containing all 8 sections:
- **Hero** — Name, title, typing effect, CTA buttons, particle canvas
- **Impact Metrics** — 4 animated counter cards (300M+ events, 90%+ cost reduction, ₹3.8Cr savings, 100% security fixes)
- **Work Experience** — Vertical timeline covering Tata Digital, Kantar, and RoboMQ
- **Featured Projects** — 6 glassmorphism cards (JARVIS, BigQuery Optimization, Observability Framework, Backfilling Framework, Search Pipeline, Data Quality)
- **Skills** — Pill-shaped tags grouped by Languages, Backend, Tools, and Strengths
- **Education** — BIT Mesra, CSE, 2021
- **Contact** — Email, phone, LinkedIn, GitHub links
- **Footer** — Copyright

### `style.css`
All styling powered by **CSS custom properties** for easy theming:
- Glassmorphism cards with `backdrop-filter: blur()`
- Gradient text using `background-clip`
- CSS Grid & Flexbox responsive layouts
- Smooth hover transforms and glow effects
- Mobile-first responsive breakpoints (1024px, 768px, 480px)
- Slide-up reveal animation class (`.reveal` → `.reveal.active`)

### `script.js`
Pure vanilla JavaScript handling all interactivity:
- **Typing effect** — types and deletes specialty titles in a loop
- **Particle system** — Canvas-based animated dots with connecting lines
- **Scroll reveal** — Intersection Observer fades in sections on scroll
- **Counter animation** — `requestAnimationFrame`-based number counters with easing
- **Navbar** — Adds `.scrolled` class on scroll, highlights active section link
- **Mobile menu** — Hamburger toggle for responsive nav
- **Scroll-to-top** — Appears after 400px scroll
